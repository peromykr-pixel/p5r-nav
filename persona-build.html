② 전기의자 스킬 카드 — 필요한 8장

빈 카드 최소 8장, 재료 페르소나 8회 소모. 모든 DLC는 이름의 피카로 여부와 여성형을 정확히 구분. 경보용 재료는 가능하면 경보 시작 전에 소환하고, 실행 미리보기에 원하는 스킬이 뜨는지 확인.

③ 라크슈미 실제 제작 · 치하야 MAX 완료

01합체 재료 확보
디오니소스(Lv.71, 고문관) + 가네샤(Lv.53, 태양) → 라크슈미(Lv.69, 운명). DLC 포함 레시피 목록에서 확인한 조합. 두 재료를 전서에서 소환해 합체 미리보기 결과가 라크슈미인지 확인한다.
02라크슈미 특성 고정
합체 특성 선택 시 연꽃이 가져오는 부를 선택. 완성 후에는 특성을 바꾸기 어려우니 먼저 확인. 전서에 초기 등록하고 진행한다.
03화염 무효 확보
데카라비아(Lv.32, 고문관)를 Lv.37까지 키워 화염 무효 습득 → 전서 등록 → 일반 교수형에서 라크슈미를 강화 대상으로 선택 → 화염 무효가 계승될 때까지 저장/불러오기. 재료의 다른 스킬도 계승 후보라 랜덤이다.
04스킬 카드 7장 적용
오토 3종, 컨센트레이트, 랜더마이저, 불굴의 투지, 순간회복을 적용. 스킬 교체 화면에서 최종 8칸을 맞춰 완성. 등록으로 중간 결과 보존.
05속 99 육성 + 선턴 실험
합체 경보 교수형 능력치 사고 반복. 목표는 속 99, 다음 내 99. 동료의 속 보정 장비나 일부 고정 턴 전투 때문에 속 99만으로 전투별 선턴 100% 보장은 아니다. 실전에서 주인공 선턴 여부 확인.

④ 오오카미 피카로 · 현재 Lv.94를 보존해서 완성

01현재 보유 8스킬 스크린샷·전서 등록
기만의 진언, 승리의 포효(기본), 불굴의 투지(Lv.92), 만능 부스터(Lv.94)가 남아 있는지 확인. 이미 덮어쓴 스킬이 있다면 덮기 전에 복구 출처부터 정한다. 현재 오오카미를 삭제하거나 재합체하지 않는다.
02스펠 마스터 카드로 즉시 적용
츠키요미 피카로를 평상시 전기의자에 넣어 얻은 스펠 마스터 카드 사용.
03얼리 댄스 교수형
라울(Lv.76 DLC, 처음부터 얼리 댄스 보유)을 재료로 오오카미에 일반 교수형. 결과는 무작위이므로 별도 저장 후 반복. 필요 시 페르소나 강화 일일 제한은 전서 등록→소지 삭제→재소환으로 우회.
04네트워크 전용 스킬 2개 획득
만능 하이부스터(Almighty Amp) + 마도의 재능(Magic Ability). 네트워크 합체에서 해당 스킬을 가진 결과를 확보하고 즉시 전서 등록. 각각 오오카미로 일반 교수형 계승한다. 게임 내 하루 1회 제한이 있어 12/10 저장 전 백업을 권장.
05완성 후 전서 등록·스탯 육성
8스킬/특성 확인 → 전서 등록 → 마력 99·내구 99·속 99 순으로 능력치 보강. 나라를 낳은 업 특성 효과를 위해 다른 페르소나 전서 등록률도 올리자.

오오카미 피카로가 이미 Lv.94라면 레벨 업 작업을 다시 할 이유가 없다. 우선 현재 배운 스킬을 확인하고, 모자라는 카드·교수형·네트워크 스킬만 확보하면 된다.

⑤ 능력치 99 · 경보 교수형 루프

라크슈미

속 99 → 내 99 → 마(선택)

목표는 선턴 + 생존. 마법 공격 담당이 아니라 마력 99는 필수 아님.

오오카미 피카로

마 99 → 내 99 → 속 99

마력은 기만의 진언 화력, 내구는 생존, 속은 명중·회피에 중요.

작업 루프: 메멘토스 전투로 합체 경보 발생(치하야 천상의 점술 활용) → 경보 중 저렴한 페르소나 둘 합체 → 이름이 노란 강화 페르소나 생성 → 이를 원하는 대상에게 경보 교수형 → 노란 재료로 사고 발생 시 능력치 합계 +10 → 반복. 증가 수치는 원하는 능력치에 균등하게 들어가지는 않는다. 기존 자유 플레이 설정으로 이미 능력치 99를 적용했다면 이 루프는 건너뛰고 스킬/특성만 확인하면 된다.

1회만 교수형을 허용하는 평상시 규칙과 달리 경보 사고는 반복 육성에 유용하다. 경보 재료를 무리하게 여러 번 돌리면 사고로 방에서 퇴장할 수 있다.

⑦ 전투 운용 · 헷갈리는 사항

일반전: 탐색 중 라크슈미 장착 → 전투 시작 시 오토 3종(5턴) → 주인공 차례에 오오카미로 교체하고 기만의 진언 → 오오카미 장착 상태로 승리 → 승리의 포효 회복 → 전투 후 장착 기억 OFF로 라크슈미 복귀.

보스전: 라크슈미로 개막 → 컨센트레이트 사용 또는 랜더마이저 → 다음 주인공 턴에 오오카미로 바꿔 강화 기만의 진언. 보스가 버프·디버프를 해제하면 라크슈미로 돌아가 갱신.

급사 방지: 불굴의 투지는 실제 장착 중인 페르소나에 있는 경우 적용. 양쪽에 설치해도 같은 전투에서 서로 독립적으로 두 번 발동하는 보험이 되지는 않는다.

행동 순서: 시작용 라크슈미의 속을 99로 만들고 동료 장비 보정까지 확인. 마하스쿠카 오토는 명중·회피 버프이지 행동 순서를 올리는 스킬이 아니다.

온라인 실패 시: 만능 하이부스터·마도의 재능 슬롯을 임시 스킬로 보존하고 온라인 기능이 정상 동작할 때 이어서 진행. 현재 오오카미를 지우거나 재합체하지 말 것.
